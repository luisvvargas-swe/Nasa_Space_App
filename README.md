# Nasa_Space_App

Proyecto en equipo de NASA Space Apps que explora el sistema solar en 3D e integra minijuegos educativos. La aplicación está desarrollada con Three.js, JavaScript y Vite.

## Aportación de Luis Vargas

Desarrollo e integración de la interfaz del sistema solar, menús de navegación y accesos a los minijuegos. El historial conserva las contribuciones del equipo y las referencias a los juegos integrados.

El proyecto web está en `solar-system-master/`. Su configuración de Vite permite establecer la ruta de publicación mediante `VITE_BASE_PATH`.
